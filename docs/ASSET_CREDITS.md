# Asset Credits & Licensing Notes — Saalim's World

All assets, procedural models, sounds, and graphics in **Saalim's World** were designed to run offline and self-contained without requiring paid third-party assets or unstable runtime CDN links.

---

## 1. 3D Graphics & Rendering Engine
- **Three.js (r160.0):** MIT License. Bundled directly in `static/js/vendor/three.min.js`.
- **Procedural 3D Models:** All 3D architectural elements (Entrance Gate, Developer Home, 6-Floor Skills Tower, AgroSense Station, LONGLINK Observatory, F1 Telemetry Circuit, Achievement Hall, and Contact Lighthouse) and the procedural Developer Character avatar are procedurally synthesized using Three.js native geometries and physically-based materials.

---

## 2. Audio & Sound Design
- **Web Audio API Synthesizer:** Custom procedural sound synthesis engine built in `static/js/world/sound.js`. Uses white/pink noise convolution filters for gentle ocean wind, and dual sine-wave bell oscillators for interactive chimes. Requires no external audio files and is muted by default.
